Matrix Rain in VICE

What you need

VICE, from vice-emu.sourceforge.io. Download the Windows build and unzip it anywhere. VICE comes with the PET's ROMs, so there's nothing else to find.

VICE is a family of emulators, one per Commodore machine. The PET one is xpet.exe, in VICE's bin folder.

Which file

Each file is a PET program, and each needs the PET model it was written for. They're in the repository's pet folder.

FilePET model in VICEWhat it is
matrix_rain_8032_noclock_v8.prgPET 8032The original, in 6502 assembly: 80 columns, 70 drops.
matrix_rain_4032.prgPET 4032The 40-column version.
matrix_rain_8032_c.prgPET 8032The same effect written in C. It draws the identical screen, but more slowly, at about 32 frames a second.

Run it from the menus

  1. Start xpet.exe. A PET starts up at the READY. prompt.

  2. Choose the PET model. Open Preferences›Settings…, go to the Model page, and pick PET 8032, or PET 4032 for matrix_rain_4032.prg. VICE resets the PET when the model changes. Close the settings window.

  3. Open File›Smart attach…, choose the .prg file, and press Autostart. VICE loads the program and types RUN for you. The rain starts a few seconds later.

Run it from a command line

One line sets the model, loads the program and runs it. From the repository's pet folder, with xpet.exe on your path, or with its full path typed in:

xpet -model 8032 -autostart matrix_rain_8032_noclock_v8.prg
xpet -model 4032 -autostart matrix_rain_4032.prg
xpet -model 8032 -autostart matrix_rain_8032_c.prg

The same line works as the Target of a Windows shortcut, if you want an icon to double-click.

Stopping it

The rain runs until you stop it; there's no key to quit. Close the window, or use File›Reset to get the PET back to READY.

If it doesn't work

The program loads but the screen is wrong, or nothing seems to run
Check the PET model matches the file. The two 80-column files need a PET 8032, and matrix_rain_4032.prg needs a PET 4032. Change it under Preferences›Settings…, then autostart the file again.

The command lines above were run exactly as shown in VICE 3.9 on Windows 11 on 18 September 2026; the screenshots come from those runs. The menu names come from VICE 3.9's manual and from the labels in the program itself.
