What you need

XRoar, from 6809.org.uk/xroar. Download the Windows build and unzip it anywhere.

XRoar also needs the CoCo's ROMs: copies of the BASIC chips inside the real machine. They don't come with XRoar. You can copy them from your own CoCo, and they can also be found on retro-computing archive sites.

ROM fileSizeNeeded for
bas13.rom and extbas11.rom8 KB eachThe CoCo 1/2 version
coco3.rom32 KBThe CoCo 3 versions
disk11.rom8 KBOnly for loading from the disk image

Put the ROM files in %LOCALAPPDATA%\XRoar\roms. Type %LOCALAPPDATA% into File Explorer's address bar to get there, then create the XRoar folder, and roms inside it. XRoar also finds ROMs placed in the same folder as xroar.exe.

Which file

Each version comes three ways: a .bin program file, the simplest to run; a .cas cassette tape image; and a .dsk disk image.

Run it from the menus

This works for the .bin and .cas files. For the disk image, see From a disk image.

  1. Start xroar.exe. It starts whichever machine it's set to by default, which may be a Dragon, the CoCo's close cousin. The next step picks the CoCo.

  2. Choose the machine from the table above: Hardware›Machine›Tandy CoCo 2B (NTSC,T1) or Tandy CoCo 3. XRoar restarts the machine.

  3. CoCo 3 only: set the TV input to match the file. View›TV input›RGB for the 80-column version, or Composite (blue-red) for the 40-column one.

  4. Open File›Run… (Ctrl+Shift+L) and choose the file. XRoar loads it and starts it. A .bin starts at once. A .cas takes a few seconds: XRoar types CLOADM and plays the tape.

From a disk image

Not yet tried in XRoar

The disk images are built and their contents checked byte by byte, but they haven't been loaded in XRoar yet, because that needs disk11.rom. The steps below follow XRoar's manual.

  1. Make sure disk11.rom is with your other ROMs. XRoar then adds a disk drive controller to the CoCo by itself.

  2. Choose the machine and, for the CoCo 3, the TV input, as in steps 2 and 3 above.

  3. Open File›Run… and choose the .dsk. XRoar inserts the disk and types DOS. The screen clears and nothing else happens. That's expected: the disk has no start-up program.

  4. Type the load command for your version and press Enter:

    LOADM"MATRIX":EXEC      CoCo 1/2, from matrix_rain_coco.dsk
LOADM"MATRIX3":EXEC     CoCo 3, RGB, from matrix_rain_coco3.dsk
LOADM"MATRIX3C":EXEC    CoCo 3, composite, from matrix_rain_coco3.dsk

Run it from a command line

One line picks the machine and TV input, loads the program and runs it. From the folder holding the files, with xroar.exe on your path, or with its full path typed in:

xroar -machine coco2bus -run matrix_rain_coco.bin
xroar -machine coco3 -tv-input rgb -run matrix_rain_coco3.bin
xroar -machine coco3 -tv-input cmp-br -run matrix_rain_coco3_cmp.bin

Swap .bin for .cas to load the same program from its tape image instead.

Stopping it

The rain runs until you stop it; there's no key to quit. Close the window, or use Hardware›Hard Reset (Ctrl+Shift+R) to get back to BASIC.

If it doesn't work

A checkerboard of orange and inverse @ signs instead of the BASIC copyright message (on a CoCo 3, some other pattern)
XRoar can't find the BASIC ROMs. Check the file names and the folder under What you need.
The 80-column CoCo 3 version is a haze of coloured dots
The TV input is set to one of the Composite options. Set View›TV input›RGB. On a composite signal, 80 columns is more detail than the colour can carry; use the 40-column matrix_rain_coco3_cmp files for that.
A CoCo 3 file doesn't run
The CoCo 3 files only run on the Tandy CoCo 3 machine. Check Hardware›Machine.

The command lines above were run exactly as shown in XRoar 1.9 on Windows 11 on 18 September 2026, with .bin and .cas files and XRoar's default memory size; the screenshots come from those runs. The menu names come from XRoar 1.9's manual. Loading from a disk image hasn't been tried yet.
